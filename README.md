# Messenger Hub

Настольная оболочка для нескольких веб-мессенджеров одновременно: WhatsApp, Telegram и Instagram.
Каждый аккаунт живёт в своём разделе сессии, поэтому несколько номеров не мешают друг другу.

## Разработка

```bash
npm install
npm start          # запуск
npm test           # проверки хранилища конфигов и выбора горячих клавиш
```

Чтобы не трогать рабочие сессии, запускайте на отдельном профиле:

```bash
MESSENGER_HUB_PROFILE_DIR=/tmp/mh-test npm start
```

Инструменты разработчика во вьюхах аккаунтов: `npm run start:devtools`.

## Сборка

```bash
npm run dist:mac
npm run dist:win
```

Готовые файлы складываются в `installers/`.

## Где лежат данные

`~/Library/Application Support/all-in-one-messengers` на macOS,
`%APPDATA%\all-in-one-messengers` на Windows. Там же файлы `desktop-accounts.json`
и `desktop-settings.json`, а в подпапке `Partitions` — сами сессии мессенджеров.

**Не меняйте поле `name` в package.json.** Путь к профилю закреплён в коде явно,
но если менять его, приложение уйдёт на пустой профиль, и это будет выглядеть как
одновременный выход из всех аккаунтов. Перед экспериментами делайте копию:

```bash
ditto "$HOME/Library/Application Support/all-in-one-messengers" "$HOME/Desktop/mh-backup-$(date +%F)"
```

## Обновления

Приложение умеет обновляться само, но адрес, откуда брать обновления, нужно задать —
по умолчанию он пустой и обновления не ищутся.

1. Соберите новую версию с увеличенным номером в package.json.
2. Выложите содержимое `installers/` (включая `latest-mac.yml` или `latest.yml`)
   на любой доступный по HTTPS адрес.
3. Пропишите этот адрес в `desktop-settings.json`:

```json
{ "updateFeedUrl": "https://example.com/messenger-hub/" }
```

Приложение проверяет обновления через 20 секунд после запуска и по команде
«Проверить обновления» в меню. Состояние видно внизу окна настроек.

**На macOS обновление требует настоящей подписи приложения.** Пока сборка подписана
ad-hoc, проверка на Mac завершится ошибкой — это ожидаемо. На Windows работает сразу.
Подпись и нотаризация — задача этапа 4.

## Ссылки и переходы

Вкладка аккаунта остаётся на сайте своего мессенджера. Всё остальное открывается
в системном браузере, и только по понятным схемам — `http`, `https`, `mailto`, `tel`.
Список разрешённых доменов лежит в [src/desktop/navigation.cjs](src/desktop/navigation.cjs)
и намеренно широкий: вход в Instagram и WhatsApp ходит через сайты Meta.

Если какой-то мессенджер вдруг перестанет пускать на нужную страницу, в логе
появится строка `Navigation to ... moved out to the system browser` — домен из неё
надо добавить в `allowedDomains`.

## Логи

Приложение пишет о себе в файл рядом с профилем:

```
~/Library/Application Support/all-in-one-messengers/logs/main.log
```

Открыть можно из приложения: **Настройки → Показать логи**. Туда попадают неудачные
загрузки аккаунтов с кодами ошибок, расписание повторных попыток, возврат аккаунта
в сеть, состояние надёжного хранилища, выбранная горячая клавиша, ошибки обновлений
и необработанные исключения обоих процессов.

Файл ограничен двумя мегабайтами, при переполнении предыдущие версии сохраняются
как `main.log.1` и `main.log.2`. Сбой записи никогда не мешает работе приложения.

Если у кого-то из коллег что-то пошло не так — попросите прислать этот файл.

## Значок в строке меню

Значок рисуется скриптом, а не берётся из иконки приложения: в строке меню macOS
нужен монохромный силуэт, который система сама перекрашивает под тему.

```bash
npm run icons:tray
```

## Структура

| Файл | Назначение |
| --- | --- |
| `src/desktop/main.cjs` | главный процесс: окна, вьюхи аккаунтов, повторные подключения, уведомления |
| `src/desktop/renderer.js` | интерфейс оболочки: список аккаунтов, настройки, палитра команд |
| `src/desktop/accounts.cjs` | аккаунты на диске |
| `src/desktop/settings.cjs` | настройки на диске |
| `src/desktop/jsonStore.cjs` | чтение с откатом на резервную копию и атомарная запись |
| `src/desktop/tray.cjs` | значок и меню в строке меню |
| `src/desktop/updater.cjs` | проверка и установка обновлений |
| `src/desktop/shortcuts.cjs` | выбор глобального сочетания клавиш с запасными вариантами |
